# mev-home 대시보드 제품 요구사항 문서 (PRD)

## 1. 개요 및 핵심 목표

본 문서는 'mev-home' 개인용 대시보드 애플리케이션의 요구사항을 정의합니다.

### 1.1. 핵심 목표
- **개인화된 정보 허브:** 일상에 필요한 정보(날씨, 시간, 메모 등)를 한 공간에서 쉽게 확인합니다.
- **빠른 조작성:** 키보드 입력을 통해 대부분의 기능을 신속하게 제어할 수 있도록 합니다.
- **정보 통합:** 여러 웹사이트나 서비스에 흩어진 정보를 한 곳으로 모으는 것을 목표로 합니다.
- **지속적인 확장성:** 새로운 아이디어가 생길 때마다 기능을 쉽게 추가하고 확장할 수 있는 유연한 구조를 지향합니다.

---

## 2. 기능 요구사항

### 2.1. 홈 (메인) 탭
- **기능 1: 실시간 정보 표시 (기존 기능)**
  - 현재 시간과 날씨를 표시합니다.
- **기능 2: 중요 메모 위젯**
  - '메모' 탭에서 사용자가 '중요'로 표시한 메모들을 홈 탭의 특정 영역에 시각적으로 보기 좋게 표시합니다.
- **기능 3: 카운트다운 타이머**
  - '설정' 탭에서 지정한 목표 시간까지 남은 시간을 시각적으로 보여주는 카운트다운을 표시합니다. (예: D-3, 12:34:56)
  - 타이머는 홈 탭 상단 (시간/날씨 위젯 근처)에 위치합니다.
  - 지정된 시간이 되어도 별도의 소리 알림은 필요 없습니다.

### 2.2. 메모 탭
- **기능 1: 메모 CRUD (기존 기능)**
  - 사용자는 새로운 메모를 작성, 수정, 삭제할 수 있습니다.
- **기능 2: 중요 메모 지정**
  - 각 메모 항목에 '중요' 여부를 표시할 수 있는 체크박스 또는 토글 버튼을 추가합니다.
  - 이 값은 '홈' 탭의 중요 메모 위젯에 어떤 메모를 표시할지 결정하는 데 사용됩니다.

### 2.3. 검색 탭
- **기능 1: 명단 검색 (기존 기능)**
  - 사용자는 명단 데이터베이스에서 특정 사용자 이름을 검색하고 관련 정보를 조회할 수 있습니다.

### 2.4. 설정 탭
- **기능 1: 명단 데이터베이스(DB) 관리**
  - 사용자가 코드를 직접 수정하지 않고, UI를 통해 '검색' 탭에서 사용하는 명단 DB 파일(예: CSV, JSON 파일)을 직접 업로드하여 기존 DB를 업데이트할 수 있는 기능을 추가합니다.
- **기능 2: 카운트다운 설정**
  - '홈' 탭에 표시될 카운트다운의 목표 날짜와 시간을 설정하고 타이머를 시작/초기화할 수 있는 UI를 제공합니다.
- **기능 3: 개인화 설정 (기존 기능 확장)**
  - 배경화면 이미지 변경
  - 로그인 PIN 번호 변경
  - 대시보드 테마(주요 색상) 변경
  - 날씨 위젯에 표시될 지역 설정

## 3. 전역 요구사항 (Non-functional)

### 3.1. UI/UX 개선
- **가독성 향상:** 애플리케이션 전반에 걸쳐 `rgba(255, 255, 255, 0.7)`와 같이 투명도가 적용되어 흐릿하게 보이는 모든 텍스트의 색상을, 불투명한 흰색 (`#FFFFFF`)으로 변경하여 가독성을 높입니다.
- **고정 레이아웃:** 데스크톱 브라우저에서도 너비가 고정된 모바일과 유사한 뷰를 유지합니다. (기존 `Todo_list.txt` 요구사항 반영)
